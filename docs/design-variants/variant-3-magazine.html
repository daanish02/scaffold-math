Apply a matrix and almost every vector rotates. A few special ones don't — they only stretch.

Apply a matrix to almost any vector, and it rotates. But for certain special vectors, the transformation only stretches or compresses them — the direction stays exactly the same. These are the eigenvectors of the matrix.

Teal lines mark eigenvector directions.
Common pitfall Not every matrix has real eigenvectors — a pure rotation turns every vector, so its eigenvalues come out complex. 
import numpy as np

A = np.array([[1.6, 0.4], [0.4, 0.9]])
eigenvalues, eigenvectors = np.linalg.eig(A)
