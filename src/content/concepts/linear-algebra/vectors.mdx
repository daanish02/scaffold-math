## Intuition

A vector is a quantity with both size and direction - think of an arrow pointing from one point to another. You can picture it as a displacement (how far and which way to move) or as a list of numbers (how far to go along each axis). Both views describe the same object.

## Formal definition

A vector{" "}
<SymbolTooltip client:visible name="vector" pronunciation="v" meaning="an ordered list of numbers, or a magnitude-and-direction quantity">$\vec{v}$</SymbolTooltip>{" "}
in $\mathbb{R}^n$ is an ordered tuple $(v_1, v_2, \ldots, v_n)$.

**Addition** (componentwise): $\vec{u} + \vec{v} = (u_1 + v_1, \ldots, u_n + v_n)$

**Scalar multiplication**: $c\vec{v} = (cv_1, \ldots, cv_n)$

**Dot product**: $\vec{u} \cdot \vec{v} = \sum_{i=1}^n u_i v_i$

**Norm (length)**: $\lVert \vec{v} \rVert = \sqrt{\vec{v} \cdot \vec{v}}$

## Common pitfalls

<Callout label="Common pitfall">
  A vector has no fixed position - $(3, 2)$ drawn from the origin and the same arrow drawn from $(1, 1)$ to $(4, 3)$ are the same vector. Only length and direction matter.
</Callout>

<Callout label="Common pitfall">
  The dot product returns a scalar, not a vector. Don't confuse it with the cross product (defined only in $\mathbb{R}^3$) or componentwise multiplication.
</Callout>
