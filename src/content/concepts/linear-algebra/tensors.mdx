## Intuition

A vector is a 1D array of numbers, a matrix a 2D array - a tensor generalizes this to arrays with any number of indices (a 3D array, a 4D array, and so on). Marked `[opt]` in the project brief; not authored this pass. Seeded here only so the prerequisite graph has a valid target for `eigenvectors` and `svd` to point to.
