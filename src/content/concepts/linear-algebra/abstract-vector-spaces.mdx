## Intuition

Everything that behaves like a vector - supports addition and scalar multiplication obeying the usual rules - counts as a vector space, even when it isn't a list of numbers: polynomials, functions, matrices themselves. Marked `[later]` in the project brief; not authored this pass. Seeded here only so the prerequisite graph has a valid target for `vectors` and `orthogonality` to point to.
